# 问题清单与优化计划

> 编写日期：2026-09-11
> 范围：`ai-girlfriend-app`（Expo 客户端）+ `ai-girlfriend-backend`（Express 后端）
> 说明：本文档汇总代码走查发现的问题，并按优先级给出建议的推进顺序，作为后续开发的待办依据。

## 0. 总体判断

客户端（Expo）的本地消息存储、发送队列、Phase 1 / Phase 2 骨架基本完成；但**后端没有对应的 Phase 2 协议实现，且注册链路是断的**，导致大量功能"写了但跑不通"。当前主要矛盾是：

- 端到端链路未打通（注册失败、AI 回复不可见、实时同步未接线）；
- 后端能力（女友定制、用户资料、统计、TTS）已实现但前端零调用；
- 媒体（图片/语音/视频）未完整同步到服务端。

---

## 1. P0·阻塞主流程（跑不起来 / 功能不可见）

### 1.1 注册接口字段不匹配，注册必然失败
- 前端 `src/api/authApi.js` `registerApi` 只发 `{ username, password }`。
- 后端 `authController.register` 要求 `email`，且 `models/User.js` 中 `email` 为 `allowNull: false` + `isEmail` 校验 → 请求永远返回 400。
- 用户名长度不一致：前端最少 2 位，`User` 模型要求 3–20 位。

### 1.2 登录只对预置 demo 用户有效
- 前端登录把用户名塞进 `email: username`（`authApi.js`），后端按 email 查询。
- 注册又不可用 → 实际只有已存在的 demo 账号能登录。

### 1.3 AI 回复永远不显示
- `ChatScreen.handleSendText` 手动调用 `sendChatApi()` 触发后端生成回复，但该响应既没有写入本地库也没有渲染。
- UI 只渲染来自 WS / sync 的消息；而 WS 未配置 → 回复丢失。

### 1.4 前端 Phase 2 协议后端完全未实现
- 后端没有聊天 WebSocket server（`comfyuiService` 里的 `ws` 是连接 ComfyUI，不是聊天）。
- 没有 `/chat/sync`、`/chat/send`，只有 `/api/chat/send`，且字段为 `content` / `mediaUrl`（前端发的是 `text`），响应也没有 `seq`。
- `globalThis.__CHAT_WS_URL__` / `globalThis.__CHAT_SYNC_HTTP_URL__` 全项目无处注入 → 实时收发 / 增量同步处于"未接线"状态。

### 1.5 后端没有 `seq` 概念
- `models/ChatMessage.js` 无 `seq` 列，而客户端增量同步强依赖 `seq`（目前仅存在 `meta_json` 里）。

### 1.6 双通道重复发送
- `sendText()` 走本地 outbox；`ChatScreen.handleSendText` 又单独发一次 REST。
- 无远端配置时 outbox 落到 mock `sendTask`，发送状态与真实后端不一致。

### 1.7 登出残留 token
- `logoutApi` 调用 `/api/auth/logout`，后端不存在该路由（404）→ `requestJson` 提前返回，`clearStoredAuthToken()` 不执行。
- `useAuth` 启动时不读取已存 token → 无自动登录 / 会话恢复。

## 2. P1·功能缺口（PRD / 文档要求但未完成）

### 2.1 媒体链路不完整
- 图片：能上传拿到 URL，但入 outbox 时把 `__LOCAL_MEDIA__` JSON 当作 `text`，真实 `/api/chat/send` 不认此格式 → 无法同步到服务端。
- 视频 / 语音：只存本地 `file://` uri，**根本没有上传**。
- 后端 `upload` 仅允许 jpg/png/gif/webp，无音频 / 视频上传接口 → 换机即丢。

### 2.2 TTS 已写但完全未接线
- `services/ttsService.js`（含情感选语气）没有任何 controller / route 调用。
- AI 回复无语音；前端也无自动播放逻辑。

### 2.3 Dify 集成未做
- `aiService.js` 仍是 OpenAI + mock 兜底；文档（`AI私密女友 - Dify模型集成与语音合成实施方案.md`）计划接 Dify 未落地。

### 2.4 文生图两条链路并存 + ComfyUI WS 未连接
- `comfyuiService.connectWebSocket()` 从未被调用 → `job.comfyOutput` 永不填充 → `pollJobResult` 只能轮询到超时；`getJobResult` 最长阻塞 5 分钟。
- job 存内存，服务重启即丢。
- 另有 `textToImageService` 通过 `/api/chat` 意图触发，两套并存需要统一。

### 2.5 前端零调用的后端能力（后端已写，UI 缺失）
- AI 女友定制：`/api/girlfriend`（GET / PUT / reset）—— 名字 / 头像 / 性格 / 年龄 / 爱好 / 声音 / 语言风格 / 背景。
- 用户资料与改密：`/api/user/info`、`/api/user/password`。
- 数据统计：`/api/stats`。

### 2.6 会话列表 / 未读 / 消息状态 UI 全缺失
- 本地 `listConversations` / `getConversationById` / `setConversationRead` 已实现但无人使用。
- `MessageBubble` 不展示 pending / failed / 重试。

### 2.7 历史消息分页缺失
- `listMessagesByConversation` 支持 `before` 游标，但 UI 只硬取 200 条，无上拉加载 / 下拉刷新。

### 2.8 命名 / 文案不一致
- `useChat` 硬编码 `BOT_USER.username = '小微'`、标题"与小微聊天中"；后端女友默认名为"小爱"。
- 左右气泡判断依赖后端硬编码 `senderId: 'zj8888'`（`chatController.js` 遗留值）。

### 2.9 情感字段空转
- `ChatMessage.emotion` 从不写入；TTS 情感分析未使用。

### 2.10 无 Push / 离线触达
- `【技术方案】-接口协议.md` 要求的 APNs / FCM 缺失。

## 3. P2·工程质量与优化

### 3.1 后端安全
- `cors()` 全开。
- JWT secret 有默认弱值 `your_jwt_secret`。
- 无 rate-limit / helmet。
- 静态 `/uploads` 目录无鉴权。
- 已声明 `express-validator` 依赖但未使用。

### 3.2 数据库
- 启动执行 `syncDatabase({ alter: true })` 自动改表（有 `MIGRATION_GUIDE.md` 却未使用迁移）。
- 后端无 conversation 表（只有按 userId 的单列表），无法支撑多会话 / 未读。
- 增量同步用自增 `sinceId`，与前端 `seq` 协议不一致。

### 3.3 性能
- `chatController.sendMessage` 同步等待 LLM / 文生图（文生图轮询可达 10 分钟）。
- `statsController` 统计最近 7 天用 7 次 count，可优化为一次 group by。
- 无缓存。

### 3.4 可观测性
- `auth` 中间件每个请求打日志，噪音较大。
- error 中间件捕获不到 Express 4 的 async 异常（需要 wrapper）。
- 无 trace_id。

### 3.5 测试 / CI
- 前后端均无测试，无 lint / CI 配置。

### 3.6 代码清理
- `useAuth` 的 `extractUser` 未使用；`authToken` state 与 `client.js` 的 token 存储重复。
- Phase 2 建议的"seq 独立列 + 索引""配置改环境变量""退出登录清理本地库"均未做。

## 4. 建议推进顺序

按"先打通主流程 → 再补实时 → 再补媒体 → 最后补页面"的顺序推进：

### A. 先打通主流程（优先级最高）
1. 修复注册 / 登录字段不匹配（补齐 email 或调整后端校验策略）。
2. 后端补 `/api/chat/send` 的 `seq` 与统一响应格式。
3. 让 AI 回复能够落库并渲染（去掉双通道重复发送）。

### B. 再补 Phase 2 实时能力
4. 后端新增聊天 WebSocket + `/chat/sync` + `seq` 列。
5. 前端注入 `__CHAT_WS_URL__` / `__CHAT_SYNC_HTTP_URL__` 配置。

### C. 再补媒体 / TTS
6. 音视频上传接口 + 媒体消息同步。
7. TTS 接入 AI 回复；前端播放。

### D. 最后补页面
8. AI 女友定制页、个人资料页、统计页、会话列表 / 消息状态展示。

### 已完成：B. 再补 Phase 2 实时能力（2026-09-11）

后端改动：
- 新增 `websocket/chatSocket.js`
  - 挂载路径 `/chat/ws`；连接时通过 query `token`（或在 `chat:join` 补传）做 JWT 鉴权。

- `controllers/chatController.js`

联调验证（已实测通过）：
- 注册 → 登录 → `POST /api/chat/send` 返回 `seq/serverId/assistantMessage`。

- WebSocket：`chat:joined` → `message:new`（用户）→ `message:new`（AI）→ `message:ack`（含 `assistantMessage`）。
